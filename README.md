# Expense Tracker

A simple command-line tool to record and total my daily expenses, written in Python.

## Features
- Add an expense with a name and an amount
- View all expenses in a numbered list
- Show the total amount spent
- A menu that keeps running until you choose to quit

## Built with
- Python 3 (no external libraries)

## How to run
1. Install Python from python.org
2. Download the project and start it:
```
git clone https://github.com/khushbooyadav-ai/expense-tracker.git
cd expense-tracker
python main.py
```

## Example
```
1. Add expense
2. View expenses
3. Show total
4. Quit
Choose: 2
1. Tea: 20.00
2. Book: 150.50
```

## What I practised
